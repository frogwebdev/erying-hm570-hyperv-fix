# Erying HM570: исправление циклических перезагрузок при запуске Hyper-V

Русский | [English](README.en.md)

Проверено на Erying HM570 с инженерным Tiger Lake-H, CPUID `806D0`, BIOS `THM570106` от 14.06.2022 и Windows 11 Pro 25H2 `26200.9711`.

**Симптом:** Windows загружается с включённым VMX, но при запуске гипервизора Hyper-V уходит в циклическую перезагрузку.

## Если Windows загружается

Открыть **командную строку от имени администратора** и выполнить:

```cmd
bcdedit /set {current} hypervisorloadoptions DISABLEHARDWAREMBEC
```

Если запуск гипервизора ранее отключали, включить обратно:

```cmd
bcdedit /set {current} hypervisorlaunchtype auto
```

Перезагрузить компьютер. **VMX и VT-d в BIOS оставить включёнными.**

## Если Windows перезагружается по кругу

Открыть **Дополнительные параметры → Поиск и устранение неисправностей → Дополнительные параметры → Командная строка**.

Посмотреть записи загрузки:

```cmd
bcdedit /enum osloader
```

Найти запись установленной Windows по строке `description`. Не выбирать `Windows Recovery Environment`.

Подставить её идентификатор вместо `{GUID}`:

```cmd
bcdedit /set {GUID} hypervisorloadoptions DISABLEHARDWAREMBEC
```

Перезагрузить компьютер и выбрать эту Windows.

## При новой установке Windows

Параметр нужно заново добавить **в запись загрузки установленной Windows на SSD до её первого запуска с гипервизором**.

Для автоматизации установочный сценарий должен выполнить это после создания загрузчика и до перезагрузки. Изменение только загрузчика установочной флешки не заменяет настройку Windows на SSD. Автоматизированная установка в рамках этой проверки не тестировалась.

## Проверка

В PowerShell:

```powershell
(Get-CimInstance Win32_ComputerSystem).HypervisorPresent
```

Ожидаемый результат — `True`.

Дополнительно проверен запуск Ubuntu в WSL2:

```powershell
wsl -l -v
```

Дистрибутив имел состояние `Running` и версию `2`.

После применения параметра подтверждена работа Hyper-V и Ubuntu в WSL2 с включёнными VMX, VT-d и защитой DMA ядра. Прошивка BIOS и переустановка Windows не потребовались.

`DISABLEHARDWAREMBEC` отключает использование аппаратного MBEC гипервизором.
